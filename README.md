## 👨‍💻 Full-stack Developer

I build web applications end to end — from the database and the API to the interface people actually click on — and I like it when the result is fast, tested and easy to maintain.

### 🚀 About Me

- 🧩 Full-stack developer working mostly with **PHP / Laravel** on the backend and **Vue / Nuxt** on the frontend
- 🤖 Building business applications, admin panels and Telegram bots
- 🐳 Shipping with Docker, Nginx and CI pipelines, from a local setup to production
- 🧪 Care about tests, static analysis and clean code
- 🌟 Author of the open-source library [htmldocx](https://github.com/Kovami/htmldocx)
